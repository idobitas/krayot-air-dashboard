תקן חוקי ≠ יעד בריאותי

מה שהחוק מתיר עדיין יכול להיות מעל יעד הבריאות של ארגון הבריאות העולמי (WHO). אפשר להחליף בין השניים במתג שבראש הדף.

ℹ️ מקרא סימונים
מקרא סימונים:
  • 🚨סבירות גבוהה מאוד לריח חריף / עשן – סימני עשן חזקים שנמשכים לפחות שעתיים
  • 💨ייתכן ריח חריף / עשן – סימני עשן בשעה האחרונה, עדיין לא מובהקים
  • 🏜️אובך מינרלי – יחס PM2.5/PM10 נמוך

🚨 שריפות גזם ופסולת מסביב מעלות חלקיקים עדינים בתחנה אחת או שתיים, בעיקר בלילה כשהרוח מהמזרח.
אבק, או אוויר עומד שמעלה את כל האזור יחד, לא נחשבים עשן שריפה.

🔴 ערך יעד (הסף הבריאותי)

הרף שרופאים וארגון הבריאות העולמי (WHO) ממליצים לא לעבור כדי להגן על הבריאות. מעליו קיים חשש בריאותי, גם אם החוק עדיין מתיר זאת.

ייבוא JSON חי מ-py-air-sviva-api

הדבק JSON שהתקבל מ-py-air-sviva-api או מ-envihaifa.net כדי להוסיף תחנה למסך הראשי ולבדוק מיד חריגות שעתיות, יומיות וחודשיות:

קוד Python להמרת יחידות וחיבור API 

# המרת פלט py-air-sviva-api (ppb/ppm) לתקנות אוויר נקי (µg/m³)
PPB_TO_UGM3 = {
    "SO2": 64.066 / 24.45,   # 1 ppb = 2.62 µg/m³
    "NO2": 46.0055 / 24.45,  # 1 ppb = 1.88 µg/m³
    "NOX": 46.0055 / 24.45,  # 1 ppb = 1.88 µg/m³
    "O3":  48.00 / 24.45,    # 1 ppb = 1.96 µg/m³
    "C6H6": 78.11 / 24.45,   # 1 ppb = 3.195 µg/m³
    "H2S": 34.08 / 24.45,    # 1 ppb = 1.394 µg/m³
    "CH2O": 30.026 / 24.45,  # 1 ppb = 1.228 µg/m³
}
# CO: 1 ppm = 1,145 µg/m³
